# Präsentation: Von der Klausur zum Förderblatt

`workflow-ki-korrektur.html` visualisiert den Ablauf der KI-gestützten Korrektur für die Schulleitung. Eine Datei, läuft offline.

- Ablauf in Bahnen (Papier, Arbeitsfläche, KI), Farbe der Station = wer handelt; Umschalter AIS.chat / Claude, Datenschutz-Ebene, Lernschleife
- Knöpfe „Klausurbogen“ und „Arbeitsfläche“: leerer Bogen mit Erklärungen (schaltbar), ausgefüllte Beispielbögen, die echte Arbeitsfläche live mit erfundenen Daten
- Tasten: ← → Schritte, P abspielen, V Vollbild, K KI-Weg, D Datenschutz, B Bogen, A Arbeitsfläche, E Erklärungen, Esc schließen

Alle Schülertexte sind erfunden. Neu bauen (z. B. nach Änderungen an der Arbeitsfläche): `cd quelle && python3 build.py`
